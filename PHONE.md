# Use Raahat on an iPhone

Raahat's existing website is responsive and can be added to an iPhone Home Screen as a standalone web app. It uses the same login, backend, and role-based features as the website; the phone still needs an internet connection to reach the server.

## Add it to the Home Screen

1. Open the Raahat site in Safari on the iPhone. The site must be reachable over HTTPS (or run locally for development).
2. Tap **Share**, then **Add to Home Screen**.
3. Keep the name as **Raahat** and tap **Add**.

Open Raahat from its new Home Screen icon. The iPhone version is not yet an App Store app, and this setup does not publish or deploy the site.
